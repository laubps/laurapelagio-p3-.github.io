# Portafolio Personal – Laura Pelagio

**Materia:** Desarrollo de Aplicaciones Web en la Nube y Móviles
**Alumna:** Laura Pelagio

## Descripción

Página web estática de portafolio personal desarrollada con HTML5 y CSS3. Incluye presentación personal, sección de proyectos, formulario de contacto y diseño responsivo adaptado a dispositivos móviles.

## Tecnologías

- HTML5 (etiquetas semánticas)
- CSS3 (variables, Flexbox, Grid, media queries)
- Normalize.css v8.0.1
- Google Fonts – Poppins
- Font Awesome 6.5 (íconos)

## Estructura del proyecto

```
proyecto/
├── index.html
├── style.css
├── normalize.css
└── img/
    └── perfil.jpg
```

## Secciones

- **Inicio (Hero):** presentación con nombre, rol y botón de contacto
- **Sobre mí:** foto de perfil, descripción y lista de habilidades
- **Proyectos:** cuadrícula de tarjetas con efecto hover
- **Contacto:** formulario con campos nombre, correo y mensaje
- **Footer:** redes sociales y datos académicos
